# Security Policy

If you discover a security vulnerability, please report it privately using
GitHub Security Advisories:

https://github.com/openwonton/openwonton/security/advisories

If you cannot access that flow, open a GitHub issue requesting a private
reporting channel and avoid including sensitive details.
