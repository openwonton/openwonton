# Quickstart

This page lists multiple methods to installing OpenWonton locally or in a sandbox
environment.

These installations are designed to get you started with OpenWonton easily and should
be used only for experimentation purposes. If you are looking to install OpenWonton
in production, please refer to the [Production Installation](/nomad/docs/install/production) guide here.

## Download a release

The quickest way to try OpenWonton locally is to download a prebuilt release.

1. Download the archive for your OS and CPU from [OpenWonton releases][releases].
2. Extract the archive and move `wonton` onto your `PATH`.
3. Verify the install: `wonton version`.
4. Start a dev agent: `wonton agent -dev`.
5. In another terminal, run `wonton status`.

If the archive name in the release differs, use the exact asset URL from the releases page.

### Linux (amd64 example)

```shell-session
$ VERSION="0.0.0" # replace with the release version, e.g. 1.6.5
$ curl -L -o /tmp/wonton.zip \
  "https://github.com/openwonton/openwonton/releases/download/v${VERSION}/wonton_${VERSION}_linux_amd64.zip"
$ unzip /tmp/wonton.zip -d /tmp/wonton
$ sudo install /tmp/wonton/wonton /usr/local/bin/wonton
```

### macOS (macosx) with arch detection

```shell-session
$ VERSION="0.0.0" # replace with the release version, e.g. 1.6.5
$ ARCH="$(uname -m)"
$ if [ "$ARCH" = "arm64" ]; then ARCH="arm64"; else ARCH="amd64"; fi
$ curl -L -o /tmp/wonton.zip \
  "https://github.com/openwonton/openwonton/releases/download/v${VERSION}/wonton_${VERSION}_darwin_${ARCH}.zip"
$ unzip /tmp/wonton.zip -d /tmp/wonton
$ sudo install /tmp/wonton/wonton /usr/local/bin/wonton
```

## Run OpenWonton in Vagrant

Alternatively, you can use a Vagrant to set up a development environment for OpenWonton.
Vagrant is a tool for building and managing virtual machine environments.

-> **Note**: To use the Vagrant environment, first install Vagrant following
these [instructions](/vagrant/docs/installation). You will
also need a virtualization tool, such as [VirtualBox][].

You can download a Vagrantfile which can start a small OpenWonton cluster. First
create a new directory for your Vagrant environment.

```shell-session
$ mkdir nomad-vagrant
```

Change into the directory you made with the previous command.

```shell-session
$ cd nomad-vagrant
```

Now you can get the OpenWonton installation configuration.

```shell-session
$ curl -O https://raw.githubusercontent.com/hashicorp/nomad/master/demo/vagrant/Vagrantfile
```

Now that you have created a new directory and downloaded the `Vagrantfile`
you must create the virtual machine with the `vagrant up` command.

```shell-session
$ vagrant up
```

This takes a few minutes as the base Ubuntu box must be downloaded
and provisioned with both Docker and OpenWonton. Once this completes, you should
see this output.

```plaintext
Bringing machine 'default' up with 'virtualbox' provider...
==> default: Importing base box 'bento/ubuntu-18.04'...
...
==> default: Running provisioner: docker...
```

At this point the Vagrant box is running and ready to go.
