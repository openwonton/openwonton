# Command: recommendation

The `recommendation` command is used to interact with recommendations.

~> Recommendation commands are new in OpenWonton 1.0 and are only available with
Nomad Enterprise.

## Usage

Usage: `wonton recommendation <subcommand> [options]`

Run `wonton recommendation <subcommand> -h` for help on that subcommand. The following
subcommands are available:

- [`recommendation apply`][recommendationapply] - Apply one or more OpenWonton recommendations
- [`recommendation dismiss`][recommendationdismiss] - Dismiss one or more OpenWonton recommendations
- [`recommendation info`][recommendationinfo] - Display an individual OpenWonton recommendation
- [`recommendation list`][recommendationlist] - Display all OpenWonton recommendations
