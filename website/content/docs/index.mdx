# OpenWonton Documentation

Welcome to the OpenWonton documentation. OpenWonton is a Nomad-compatible
scheduler and workload orchestrator. This documentation is a reference for all
available features and options of OpenWonton. If you are just getting started with
OpenWonton, please start with the [Getting Started collection][gs]
instead.

OpenWonton exists to maintain and evolve the MPL-2.0 licensed Nomad codebase for
community use while preserving compatibility for existing operators.

Nomad is a trademark of HashiCorp, Inc. OpenWonton is not affiliated with,
endorsed by, or sponsored by HashiCorp.
