# Plugins

OpenWonton includes a plugin framework which allows users to extend the
functionality of some components within OpenWonton. The design of the plugin system
is inspired by the lessons learned from plugin systems implemented in other
ecosystem products such as Terraform and Vault.

The following components are currently pluggable within OpenWonton:

- [Task Drivers](/nomad/plugins/drivers)
- [Devices](/nomad/plugins/devices)
