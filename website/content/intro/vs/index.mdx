# OpenWonton vs. Other Software

The following characteristics generally differentiate OpenWonton from related products:

- **Simplicity**: OpenWonton runs as a single process with zero external dependencies.
  Operators can easily provision, manage, and scale OpenWonton. Developers can easily
  define and run applications.
- **Flexibility**: OpenWonton can run a diverse workload of containerized, legacy,
  microservice, and batch applications. OpenWonton can schedule service, batch
  processing and system jobs, and can run on both Linux and Windows.
- **Scalability and High Performance**: OpenWonton can schedule thousands of containers
  per second, scale to thousands of nodes in a single cluster, and easily federate
  across regions and cloud providers.
- **Ecosystem Interoperability**: OpenWonton integrates with Vault for secrets
  management and Consul for service discovery and dynamic configuration. OpenWonton's
  Consul-like architecture and Terraform-like job specification lower the barrier
  to entry for existing users of the Terraform, Consul, and Vault ecosystem.

There are many relevant categories for comparison including cluster managers,
resource managers, workload managers, and schedulers. There are many existing
tools in each category, and the comparisons are not exhaustive of the entire space.

Due to the bias of the comparisons being on the OpenWonton website, we attempt to only
use facts. If you find something that is invalid or out of date in the comparisons,
please [open an issue](https://github.com/openwonton/openwonton/issues) and we will
address it as soon as possible.
