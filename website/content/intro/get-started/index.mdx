# Getting Started with OpenWonton

OpenWonton is compatible with Nomad 1.6.5 and uses the `wonton` CLI. This guide
walks you through a local dev setup so you can run a job and explore the UI.

## What you will do

- Install the OpenWonton CLI.
- Run a local development agent.
- Deploy and update a job.
- Explore the Web UI.
- Clean up your local environment.

## Before you begin

- An OpenWonton binary available on your PATH.
- Docker running locally if you want to use the container example.
- Open ports 4646 to 4648 on your machine.
