# OpenWonton Security

We understand that many users place a high level of trust in OpenWonton and the tools we build. We apply best practices and focus on security to make sure we can maintain the trust of the community.

We deeply appreciate any effort to disclose vulnerabilities responsibly.

If you would like to report a vulnerability, please use the GitHub Security Advisories flow at https://github.com/openwonton/openwonton/security/advisories. Please **do not create a GitHub issue for security concerns**.

If you aren't reporting a security sensitive vulnerability, please open an issue on the standard [GitHub](https://github.com/openwonton/openwonton) repository.
