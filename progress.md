# OpenWonton Test Fixes

This file tracks the progress of fixing the failing tests after the `nomad` to `openwonton` rename.

## Notes

- 2025-02-XX: User reported `make test-nomad | grep FAIL` output; waiting on full test logs per-package when we rerun tests with output redirected to files.
- 2025-02-XX: Initial scan of failing areas (TLS, escapingfs, template manager, docker, qemu) shows most strings still hardcoded as `nomad` for TLS domains, cert file names, env vars, and docker labels; no obvious `wonton` string literals in those packages beyond import paths. Likely root causes are a mix of rename-induced behavior changes vs. environment-dependent test assumptions.
- 2025-02-XX: Noted that several CLI tests still embed `nomad` command strings (autocomplete, integration tests, tls cert create). We likely need to decide which of these stay `nomad` for compatibility vs. update to `wonton` for user-facing CLI output expectations.
- 2026-01-17: Implemented CLI rename and compatibility shim: moved primary entrypoint to `cmd/wonton`, added Go-based `cmd/nomad` wrapper that forwards to `wonton`, and updated build/release packaging to ship both binaries. Updated top-level CLI name/help usage to `wonton` and adjusted shared error text to reference `wonton`.
- 2026-01-18: Updated CLI help/examples to prefer `wonton`, rebranded version output to `OpenWonton v...`, and switched Docker entrypoint to exec `wonton` while keeping a compatibility skip env var for warnings.
- 2025-02-XX: Ran focused tests. `helper/escapingfs` failed due to symlink escape detection; `helper/tlsutil` failed due to expired cert testdata (system time is 2026); template env test passed.
- 2025-02-XX: Fixed symlink escape check in `helper/escapingfs` and added TLS test time override in `helper/tlsutil` plus a default `NOMAD_TLS_TEST_TIME` in `ci` to keep test certs valid without regenerating them.
- 2025-02-XX: Adjusted symlink escape check to compare cleaned resolved path against base prefix to avoid incorrect `filepath.Rel` behavior in tests.
- 2025-02-XX: Further adjusted symlink escape check to resolve the base path with `EvalSymlinks` before prefix comparison to handle temp dir symlink components.
- 2025-02-XX: Added `tlsutil.TestTimeFunc` and wired `command/agent` TLS HTTP tests to use the fixed test time for certificate validation.
- 2025-02-XX: `command/agent` TLS tests now pass after setting `Time` on TLS configs in `TestHTTP_VerifyHTTPSClient_AfterConfigReload`.
- 2025-02-XX: Adjusted alloc migration test to wait for the new alloc to reach `AllocClientStatusRunning` before checking migrated file.
- 2026-01-16: User reported remaining failures from a full run: `client/allocrunner` restore, multiple `client/allocrunner/taskrunner` and `template` tests, `command` event stream and job restart, `command/agent` fresh alloc metrics, several `drivers/docker` tests (exec streaming, capabilities, image GC, host network, stop signal), and `nomad` tests (`Encrypter_KeyringReplication`, `Leader_PeriodicDispatcher_Restore_Adds`, `Monitor_Monitor_RemoteServer`, `NodeMeta_Forward`, `VaultClient_SetConfig_Deadlock`).
